JOM BACA - SETUP AKAUN EMAIL + VERSI PENUH

1. Buka Supabase Dashboard > project Jom Baca > SQL Editor.
2. Copy semua isi fail supabase-setup.sql dan Run.
3. Pergi Authentication > Providers > Email. Pastikan Email provider ENABLED.
4. Untuk setup paling mudah semasa testing, boleh matikan "Confirm email" dahulu.
   Jika Confirm email ON, user perlu klik link pengesahan dalam email sebelum boleh login.
5. Deploy semua fail website yang telah dikemaskini.

FLOW CUSTOMER BARU
- Beli RM9.90 melalui WhatsApp.
- Daftar / login menggunakan email.
- Masukkan unlock code sekali.
- Code akan attach kepada akaun tersebut.
- Selepas itu user hanya perlu login untuk dapat semula versi penuh.

FLOW CUSTOMER LAMA
- Daftar / login menggunakan email.
- Masukkan semula unlock code lama.
- Jika code lama pernah digunakan sebelum sistem akaun dan used_by masih kosong,
  sistem akan attach code itu kepada akaun email tersebut.

GENERATE CODE BARU
select * from public.generate_unlock_codes(20);

SEMAK USER PREMIUM
select user_id, email, is_premium, premium_since, redeemed_code
from public.profiles
order by created_at desc;
